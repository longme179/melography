### Decisions recorded

1. **WB = cone gains, not Kelvin.** Round-trip exact through
   analysis↔synthesis; a CCT parameterization needs a Planckian-locus
   table (documented follow-up). McCamy CCT is display-only.
   Geometric-mean normalization keeps luminance in EV's job.
2. **Shaping knots measured post-EV** (the operator applies the curve
   after the EV scale — knot sources must live in the same domain).
   Caught by the benchmark: pre-EV knots lifted crushed-scene midtones
   +1.6 stops. Aggregate improved 0.29 → 0.20.
3. **v1 ships baseline-only.** No candidate passed the gate (all weights
   licenses unverified; Zero-DCE unlicensed = rejected). ADR-0004 §7:
   acceptable outcome, not a failure. The network downloader therefore
   ships **with the first gate-passing model** — an HTTPS client with an
   empty registry is unreachable attack surface. Offline install from
   local files is the tested path (CLI + app).
4. **The benchmark is the product of #14.** Synthetic ground-truth
   corpus; metrics ev/wb/clip; aggregate = ev + 5·wb + clip; baseline
   0.205 vs naive-ONNX 1.019; CI job `ai-onnx` asserts the baseline wins
   — any future model must beat 0.205 there.
5. **ort behind feature `onnx`** (default off keeps the workspace light;
  CI runs the onnx tests explicitly — same pattern as the film release
  gates).

### Sandbox sysroot note (reproducibility)

The app tree needs GTK/WebKitGTK headers even for `cargo check`
(tauri → muda/tauri-runtime pull -sys crates on Linux). No sudo in the
sandbox → extracted ~60 dev+runtime `.deb`s via `apt-get download` +
`dpkg-deb -x` into `/tmp/sysroot`, fixed dangling `.pc` symlinks, then:

```sh
export PKG_CONFIG_PATH=/tmp/sysroot/extracted/usr/lib/x86_64-linux-gnu/pkgconfig
export LIBRARY_PATH=/tmp/sysroot/extracted/usr/lib/x86_64-linux-gnu
export LD_LIBRARY_PATH=/tmp/sysroot/extracted/usr/lib/x86_64-linux-gnu
cargo check --all-targets && cargo test   # app tree, gui features — 8/8 green
```

This replaces the M1-era "rebuilt sysroot" hack and is cheaper than
building glib/gtk from source. CI's app-build job remains the
authoritative gate.
