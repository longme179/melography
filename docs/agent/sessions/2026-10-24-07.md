### Sandbox environment notes (reproducibility)

The sandbox was reset before this session: rustup 1.99.1 reinstalled,
sysroot rebuilt (`scripts/sysroot_rebuild.sh` pattern: apt-cache
recursive dependency closure → batch `apt-get download` → `dpkg-deb -x`
→ retarget dangling `.so` symlinks at system paths — dev packages ship
symlinks whose targets are system-installed runtime libs). **Toolchain
1.99 defaults to lld**, which ignores `LIBRARY_PATH` — the fix is
`RUSTFLAGS="-L <sysroot>/usr/lib/x86_64-linux-gnu"`. Disk discipline
mattered again (session 06 hit it; this session hit it twice): the app
tree needs ~5 GiB of debug artifacts, shared `CARGO_TARGET_DIR` +
dropping incremental/large binaries between phases is the working
pattern. All in `scripts/appenv.sh`.
