### i18n — zero embedded strings (UX_SPEC §10)

   tooltips and the provenance honesty line through the catalogs; every
   knob converted to the shared `Slider` (double-click reset, arrows,

   slider" contract now holds on every panel; grain/halation reuse the
   `grain.*` keys, scaled ×100 like GrainHalationPanel).
2. **`StockBrowser.svelte`** — title/close/empty/aria localized; backend
   enum values (provenance/confidence/polarity/layers/path) display via
   the new **`tEnum(prefix, value)`** helper: known values localize,
   unknown values fall back to the raw token — data-driven enums never
   crash and never leak a raw key. Theme-token colors replace the
   hardcoded `#20242b` sheet (light/contrast themes are now correct).
3. **`Settings.svelte`** log levels localized; **17 missing Rust error
   codes** received EN/VI guidance entries — coverage is now **28/28**
   `AppError::new` codes (the audit enforces it).

   comma decimal separator) — Viewport (render ms, zoom %), TonePanel

   follows the live language (`$:` reactive, not a frozen const).

### Pseudo-locale CI (UX_SPEC §10 "pseudo-locale test build")

5. `vite build --mode pseudo` (npm `build:pseudo`): `import.meta.env.MODE`
   gates a wrap that accents vowels and pads **proportionally ≥ 40%**
   (`[̃ stríng ẊẊẊ…]`, placeholders intact). Proportional — the first
   draft's fixed `+n` padding only stressed short strings (the audit
   caught it: 78% < 95% gate). Bundle-verified: wrap loop present and
   unconditional in the pseudo build, fully tree-shaken from the normal
   build (191.70 vs 191.45 kB).
6. **`scripts/ui_i18n_audit.mjs`** (pure Node, no deps; CI step in
   `app-build`): 7 gates — EN↔VI parity (323/323, no dups/empties),
   placeholder parity, VI diacritics ≥80% (measured **95.0%**), VI
   length ≤3.5× EN (worst 3.00×), Rust error-code coverage (28/28 from
   11 rs files), embedded-string scan of all 22 svelte files (**0 hits**,
   15-entry justified allowlist), pseudo-transform sanity.

### A11y (UX_SPEC §8/§10)

7. **`scripts/ui_contrast_audit.mjs`** (CI step): parses app.css tokens,
   computes WCAG 2.1 ratios for 54 pairs × 3 themes. **Found 2 real AA
   failures + 1 zero-headroom pair, all fixed**:
   * light primary-button label ink-on-fill 3.65 → `--accent-500
     #aa7a20` → **4.84**
   * light `--fg-tertiary` on bg-elevated 4.28 → `#61656c` → **4.96**
   * dark `--fg-tertiary` 4.51/4.14 (the elevated pair was unchecked
     before) → `#82898f` → **5.02/4.61**
8. **SR announcements**: toast gained `role="status" aria-live="polite"`;
   Viewport gained a visually-hidden debounced (400 ms) render-status
   announcement ("Rendered in {ms} ms" / "Đã kết xuất trong {ms} ms").
9. **Dialog a11y**: Esc now closes **every** dialog (Export and
   Import-LUT were missing it; suppressed while busy); Settings/
   PresetManager backdrop-click dismissal removed on purpose (accidental
   draft loss > one extra click); StockBrowser got `aria-modal` + Esc +
   initial focus on Close; ✕ buttons announce "Close"/"Đóng", not the
   glyph.
10. **Home recents**: `<li role="button">` → a real `<button>` inside
    the li (keyboard/focus native; the Svelte a11y linter is now **clean
    repo-wide — 0 warnings, was 7**: li-role, viewport tabindex,
    overlay keydown ×2, labelless control, unused CSS ×3).
11. **CSS floors**: `button/select/input` min-height 32px (documented
    exemption: the Slider `.val` click-to-type readout);
