## 2. Delivered

### Backend

1. **`export.rs` — ONE standalone export path** (the session's real
   refactor): `export_image` and the batch worker now run the same
   `run_export(stages → report)`. Routing is **preview-consistent**,
   fixing two real M2/M3 single-export inconsistencies:
   * a film stock with `enabled=false` previously took the film path —
     which silently DROPPED the LUT stack (the preview applied it);
     now it routes to the LUT/tone leg exactly like `film_leg()`;
   * a disabled first LUT was previously APPLIED on export while the
     preview skipped it; now the first *enabled* LUT wins
     (`resolve_stack()` semantics).
   Also: film exports now write their sidecar (provenance next to the
   output — LUT exports always did), and film-active + LUT stages
   surface `export.lut_skipped_by_film` as a *warning*, never a silent
   drop. Collision-safe output naming (`-2`, `-3`…) never overwrites.
2. **`batch.rs` — the S6 queue**: jobs carry their own stages snapshot
   (**retry keeps settings** is structural), a strictly-sequential
   worker thread (deterministic + memory-bounded) decoupled from
   `EditorState` — the editor never waits on a render; `batch://update`
   events + every command returning the full snapshot `{jobs, paused}`.
   Honesty rules: missing stock → per-row `stock.missing` error at add
   time (never wrong colors), ENOSPC → `io.disk_full` + folder-chooser
   hint, rendering files cannot be "cancelled" mid-call (pause stops
   the NEXT file — the UI says so).
3. **`wb_pick` + `render::wb_gains_for_region`**: eyedropper math =
   mean AP1-linear RGB over an edge-clamped 5×5 window through the
   SAME `analysis_gains_for_gray` as auto-lighting (one WB path);
   normalized coords; undo-able recipe mutation.
4. **`load_ap1`** helper extracted (open_image + batch thumbs share one
   decode path); `StateJson.source_path` (S6 add-to-batch);
   `now_rfc3339`/`base64_encode`/`presets_dir` became `pub(crate)`.
