## Bugs the gates caught (kept for the record)

* Grain bilinear read stale rows beyond the strip's valid density rows at
  image edges → tiled≠monolithic at strip_h=1. Fixed: explicit out-of-frame
  → zero-density rule + valid-row contracts.
* Halation clamped taps to plane-allocation bounds instead of the valid
  input rows → latent seam at native resolutions. Fixed: `valid_rows`
  parameter; zero padding beyond (matches monolithic).
* Zoom consistency failed +95 % without supersampling (aliasing) — fixed
  with pixel-area supersampling (physical: a sensor pixel is an area
  average).
* Mono M_exc luminance rows are not diagonal-dominant; the 18 % anchor
  averaged dead layers; the γ guard iterated dead layers — all mono-fixed.
* Print-path test had the photographic polarity backwards twice (paper is
  negative-working; bright subject ⇒ dense negative ⇒ thin print). The
  failing tests drove the correction — the physics reads right now.
